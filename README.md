# Weekly Report Generator

CSV로 내려받은 일감 목록을 주간업무보고 형식의 텍스트로 변환해 주는 단일 페이지 웹 도구입니다.
`index.html` 파일 하나로 동작하며, 별도 서버나 빌드 과정이 필요 없습니다.

## 사용 방법

1. `index.html`을 브라우저에서 엽니다. (GitHub Pages로 배포된 페이지를 그대로 써도 됩니다.)
2. 출력 옵션을 고릅니다.
   - `사업관리 포함` / `사업관리 제외`
3. 일감 목록 CSV 파일(`.csv`)을 선택하고 **보고서 생성하기**를 누릅니다.
4. 결과 영역에 만들어진 보고서를 **결과 복사하기**로 클립보드에 복사합니다.

## CSV 형식

첫 줄은 헤더이며, 다음 열 이름을 사용합니다. (`#`, `상태`, `제목`은 필수)

| 열 이름 | 설명 |
| --- | --- |
| `#` | 일감 번호 |
| `상위 일감` | 상위 일감 번호 (선택) |
| `범주` | 분류 (선택, 없으면 `미분류`) |
| `상태` | `신규` / `진행중` / `완료` |
| `제목` | 일감 제목 |
| `변경` | 변경 일시 (선택, 완료 건의 금주 여부 판단에 사용) |
| `진척도` | 진척도 % (선택, 100 이상이면 완료로 처리) |

CSV는 EUC-KR 인코딩을 기준으로 읽습니다.

## 동작 방식

- 이번 주 월요일~금요일을 기준으로, `신규`·`진행중` 일감과 금주에 변경된 `완료` 일감을 모읍니다.
- 범주 → 상위 일감 순으로 묶어 정리하고, 상위 일감이 있으면 평균 진척도를 함께 표시합니다.
- 파일 선택과 변환은 모두 브라우저 안에서만 이루어지며, 입력한 CSV가 외부로 전송되지 않습니다.
